# CFD Visualization Images

This folder contains selected visualization results from the bow-thruster CFD post-processing project.

## Images

- `q_range_calibration.png` — Q-criterion display-range comparison
- `tip_vortex.png` — Blade-tip vortex visualization
- `hub_junction_vortex.png` — Hub and junction vortex visualization
- `transient_q_frames.png` — Representative transient Q-criterion frames
- `total_pressure.png` — Total-pressure field visualization
- `moving_pressure_slices.png` — Moving total-pressure slice stages

For the complete project methodology, results, and interpretation, see the main repository README.
